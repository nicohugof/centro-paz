## 1. Flujo de Derivación Bidireccional (Protocolo Clínico Cerrado)

El mayor dolor de un psiquiatra al derivar a psicoterapia o psicodiagnóstico es la **"caja negra"**: no saber si el paciente llegó, qué pruebas se aplicaron, cuál fue el resultado o cuándo se ajustarán los objetivos terapéuticos. Centro Paz resuelve esto mediante un ciclo de comunicación cerrado:

```
                            ┌──────────────────────────────────────────────┐
                            │  1. DERIVACIÓN MÉDICA (Psiquiatra ➔ CPAZ)    │
                            │  Paciente derivado con orden o contacto.     │
                            └──────────────────────┬───────────────────────┘
                                                   │
                                                   ▼
                            ┌──────────────────────────────────────────────┐
                            │  2. NOTIFICACIÓN DE INGRESO (CPAZ ➔ Médico)  │
                            │  WhatsApp/email breve confirmando recepción. │
                            └──────────────────────┬───────────────────────┘
                                                   │
                                                   ▼
                            ┌──────────────────────────────────────────────┐
                            │  3. PSICODIAGNÓSTICO O PSICOTERAPIA          │
                            │  • Batería psicométrica (BDI-II, BAI, PAI).  │
                            │  • Alerta roja inmediata ante riesgo activo. │
                            └──────────────────────┬───────────────────────┘
                                                   │
                                                   ▼
                            ┌──────────────────────────────────────────────┐
                            │  4. INFORME CLÍNICO EN 10 DÍAS HÁBILES       │
                            │  Entrega al paciente + contrarreferencia     │
                            │  ejecutiva directa al psiquiatra tratante.   │
                            └──────────────────────┬───────────────────────┘
                                                   │
                                                   ▼
                            ┌──────────────────────────────────────────────┐
                            │  5. DERIVACIÓN INVERSA (CPAZ ➔ Psiquiatra)   │
                            │  Pacientes espontáneos de CPAZ que precisan  │
                            │  evaluación médica se derivan a la red.      │
                            └──────────────────────────────────────────────┘
```

### Etapas Operativas del Protocolo:

1. **Recepción y Acuse de Recibo (Día 1):**  
   Al agendar la primera sesión del paciente derivado, la coordinación de Centro Paz envía un mensaje breve al psiquiatra confirmando que el paciente ya tiene hora fijada.
2. **Canal de Alerta Temprana (Inmediato):**  
   Si durante las sesiones de evaluación se detecta ideación autolítica activa, suspensión abrupta de psicofármacos o síntomas psicóticos no reportados, Valentina contacta de inmediato al psiquiatra tratante por vía telefónica o WhatsApp clínico.
3. **Cierre de Evaluación & Emisión de Informe (Máximo 10 días hábiles):**  
   Tras la última sesión de evaluación, se emite el informe pericial estructurado (DSM-5-TR / CIE-11) y se entrega una copia al paciente con una sesión de devolución; simultáneamente se envía una minuta médica o copia autorizada al psiquiatra para su próximo control.
4. **Contrarreferencia y Seguimiento Periódico:**  
   En procesos de psicoterapia continuada, se remite un reporte semestral de evolución (o al solicitarlo el médico) para apoyar la decisión de titulación, mantención o retiro de psicofármacos.
5. **Derivación Inversa a la Red:**  
   Centro Paz recibe decenas de consultas mensuales de pacientes sin médico tratante. Aquellos con cuadros moderados a severos de ansiedad, depresión mayor, bipolaridad, TDAH descompensado o TLP son derivados de forma prioritaria a los psiquiatras miembros de nuestra red aliada.
